# হালিমা সাদিয়া (রা.) মহিলা মাদ্রাসা ও নূরানী কিন্ডারগার্টেন

## এই ZIP-এ নতুন কী আছে
- `index.html` — মূল ওয়েবসাইট
- `style.css` — ডিজাইন
- `assets/logo.jpg` — মাদ্রাসার আসল লোগো
- `assets/image1.png` — নতুন ডিজাইন করা ৩-লাইনের ব্যানার
- `result.html` — ফলাফল পেজ
- `admin.html` — অ্যাডমিন প্যানেলের প্রাথমিক কাঠামো
- `supabase/schema.sql` — ফলাফল ডাটাবেসের কাঠামো

## GitHub-এ আপলোড
ZIP ফাইল GitHub-এ সরাসরি আপলোড করলে ফাইলগুলো খুলবে না। ZIP খুলে ভেতরের ফাইলগুলো repository-এর root-এ আপলোড করবেন। `assets` ফোল্ডারসহ আপলোড করবেন।

## গুরুত্বপূর্ণ
Supabase-এর service-role key কখনও GitHub-এর HTML/JS ফাইলে রাখবেন না।
